# Mihrab Energi Indonesia

Website statis PT Mihrab Energi Indonesia — jaringan SPKLU (stasiun pengisian kendaraan listrik umum) di masjid-masjid Pulau Jawa.

Struktur dan gaya mengikuti website Pro Mutu Andalan (HTML + CSS + JavaScript murni, tanpa build).

## Halaman

- `index.html` — Beranda
- `cara-kerja.html`, `manfaat.html`, `teknologi.html`, `lokasi.html`, `faq.html`
- `daftar.html` — formulir pendaftaran masjid (dikirim ke WhatsApp)
- `mengapa-spklu-di-masjid.html`, `skema-bagi-hasil-syariah.html` — artikel

## Sebelum online

1. Ganti `62XXXXXXXXXX` dengan nomor WhatsApp resmi di semua file (`script.js` dan `*.html`).
2. Ganti `info@mihrabenergi.id`, `[+62 8xx-xxxx-xxxx]`, dan `[Alamat kantor]`.
3. Ganti `[10]%` bagi hasil dan `[10] tahun` masa kerja sama sesuai keputusan final.
4. Ganti `pattern.svg` dengan foto SPKLU asli bila sudah ada, dan sematkan peta di `lokasi.html`.
